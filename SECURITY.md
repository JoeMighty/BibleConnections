# Security

Bible Connections is a static website with no accounts, no server and no stored personal data. Notes and settings stay in each visitor's browser.

## Reporting a problem

If you find a security problem (for example a way to run code through a shared link, a collection or a church page), please email **hello@bibleconnections.app** rather than opening a public issue. Include the steps to reproduce it. You should get a reply within a week, and a fix will be credited in the changelog if you would like.

## Scope

- The site at https://bibleconnections.app and the code in this repository.
- Not in scope: Bible.com, GitHub and other sites the project links to.
