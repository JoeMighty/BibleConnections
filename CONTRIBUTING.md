# Contributing to Bible Connections

Thank you for helping. There are three easy ways to contribute.

## 1. Suggest content

Open an issue with the **Content suggestion** form: a better note, a new journey, a discussion question or a Spanish translation fix. Content can also be edited directly on GitHub; see [docs/EDITING.md](docs/EDITING.md).

Please write in your own words. Do not copy or closely paraphrase verses from copyrighted translations such as the NIV, ESV, NVI or RVR1960.

## 2. Report a problem

Open an issue with the **Something is not working** form and include the link from your browser's address bar.

## 3. Improve the code

1. Fork the repository and create a branch.
2. Run the site locally with `npm run serve` and the tests with `npm test` (see the README).
3. Keep the site accessible: every feature must work with a keyboard and a screen reader, and the axe tests must pass.
4. Add a line to the **Unreleased** section of [CHANGELOG.md](CHANGELOG.md).
5. Open a pull request describing what changed and why.
